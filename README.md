# PhyChord

支持亮色／暗色主题、离线运行的古典和声学习与分析软件。应用是内嵌 CSS / JavaScript 的 `index.html`，不加载外部字体、CDN 或分析服务。

## 输入与界面

学习模式：左上双谱表，右上和弦、功能及折叠详情，底部 88 键钢琴。虚拟键盘可点击选择音符；也可使用本地 MIDI。

演奏模式：仅 MIDI 可录入音符。鼠标琴键禁用，五线谱与钢琴只显示当前按下的 MIDI 音符；不录制。

Chrome / Edge 中连接键盘后点击“连接 MIDI”。浏览器需要安全上下文；file:// MIDI 不可用时，在本目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。无需互联网。

## 设置与主题

“设置”可选择跟随系统、亮色或暗色，以及本机 MIDI 输入设备。自动模式实时响应系统外观变化；手动主题与设备选择保存在本机。亮色为白底黑字黑谱线，暗色为黑底白字白谱线，独立谱面窗口同步。切换 MIDI 设备会清除上一设备按下状态，其他未选输入不参与分析。

主界面左上谱面固定 5:4。谱号、大谱表括号及全音符采用 Bravura 标准矢量轮廓（SIL OFL 1.1），无外部字体请求；许可见 LICENSE-Bravura.txt，亦内嵌 HTML。字体风格向参考图匹配，但参考图字体未经确认，不保证逐像素一致。演奏模式每次 note on/off 都基于当前按下集合重新显示音响与功能，避免沿用已抬起音符。

## 全音符乐谱

学习模式点“打开乐谱”。仅使用无符干全音符，没有拍号、小节线、手动音名输入或四部配音控件。

- 鼠标左键在谱线上点音，横向位置自动吸附和弦列，纵向位置吸附线/间。工具栏选择随调、升降或还原。
- 右键点单个音符删除。回车在光标后插入空和声位（末尾空光标则原位创建）；左右方向键自由移动光标。
- MIDI 按键收集为一个和声，所有 MIDI 音符释放后提交一次，绿色光标自动后移。部分释放不会重复提交。
- Delete / Backspace 删除光标所在的当前和声，保留其他和声；末尾空光标不删除前面的内容。
- 同一连接的变音符按音名和八度延续；自然音开头不加还原符号，取消既有变化或调号变化时才显示还原号。
- 乐谱与底部钢琴等宽，超出内容可横向滚动，缩放条改变横向显示比例。
- 双击谱面打开独立 A4 比例谱面窗口：仅有谱表、音符和光标，无和弦标签、钢琴或文字面板。可通过系统窗口操作拖动；鼠标编辑与 MIDI 输入和主窗口同步。关闭独立窗口后可继续在主窗口编辑。浏览器需允许弹窗。
- 和弦功能标在相应列下；乐谱本机保存、自动恢复，支持试听与多候选连接建议。

连接建议在未确认声部时只视为功能/音响候选；四音配音可按音区估计进行内部规则检查，但不宣称已识别真实声部。无拍号的乐谱不推断强弱拍或确定终止位置。

## 流行标记

支持基础三/七/九和弦、转位、六和弦、挂留、双和弦及十一/十三和弦常见配音。属十一常省略三音；保留三音的完整属九加十一标作 `9(add11)`。属十三常省略十一，也支持省略五/九音的配音。相同音响的功能解释仍需调性与上下文，不以模板证明历史名称。

## 验证与范围

```sh
npm ci
npm test
```

浏览器测试需 Playwright 与 Chromium（默认 `/usr/bin/chromium`，可用 `PHYCHORD_CHROMIUM` 指定）。覆盖和声、拼写、全音符、变音延续、扩展和弦、MIDI 提交边界、鼠标吸附/删除、光标退回、缩放、独立窗口双向编辑及本机保存。

这是教学乐谱，不是完整 Sibelius 排版器。暂未实现所有调性/枢纽规则、自动声部分离和完整历史风格验收；复杂声部和等音转调保留候选。理论规则仍需持续教材式正反例与专家审校。

PhyChord 1.0 恢复 Windows/macOS 桌面发行，网站部署仍暂停。Windows 使用 Setup.exe 安装；macOS ZIP 解压后将 PhyChord.app 拖入 Applications，原生 macOS 发布流程同时提供 DMG。按处理器选择 x64（Intel/AMD）或 arm64（Apple Silicon/Windows ARM）。当前版本未签名、未经 Apple 公证，操作系统可能提示来源未验证。桌面程序本地运行，MIDI 不经过云端。

设置中的“键位”可查看鼠标、回车、删除及左右键说明。没有音符时和弦区留空；单音/双音显示带八度的音名，如 `C#3，D2`。MIDI 连接失败文字不在页面显示。

## 谱面标记与播放

页首仅保留 PhyChord。播放器采用圆形播放/暂停图标，乐谱从头按 52 BPM 依次播放，每个和声一拍（跳过空和声位）。暂停后可继续，播放结束后回到播放图标，再次播放从头开始。

选中和弦的绿色光标位于该和弦右侧，底部钢琴高亮完整和弦。谱下依次显示斯波索宾功能、罗马数字和流行符号。起始调性在低音谱号下以方框显示：大调大写，小调小写，变音前置（bB、#f）。新调框和调内共同和弦的双重功能括号遵循 [THEORY_SOURCES.md](THEORY_SOURCES.md)，其余情况不强行给出中介和弦。独立 A4 窗口仍只显示纯谱面，不显示分析标签。

当前开发版新增古典/流行模式与本地合成钢琴。设置可关闭钢琴声音、调节音量；MIDI CC64 控制延音，松键仍立即从实时识别集合中移除。流行模式不推断调性，不显示古典功能；sus、6/9、加音及变化和弦保留多解。钢琴为轻量合成近似，未复现 Pianoteq 专有物理模型。删除后新输入会在前一和声后插入，保留已有内容。

PhyChord 1.1 已移除双击谱面竖屏窗口，保留横向乐谱编辑。下载版本以 v1.1.0 标签和 PhyChord1.1 文件名为准。
